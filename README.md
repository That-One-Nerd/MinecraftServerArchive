# Archive/VarietyServer2

This server was a multiplayer variation of skyblock! It has some very rarely-spawning extra islands. The server got a nice amount of use, we did quite a lot. Like all (most) variety servers, it was open for three weeks.

- Runtime: **6/1/2025 to 6/22/2025** (22 days)
- Version: Minecraft **1.21.5**
- Datapack Used: [Skyblock Infinite](https://modrinth.com/datapack/skyblock-infinite) **v1.1.6**

---

*A note for anyone trying to recreate this setup: This particular version of Skyblock Infinite creates tons of ugly trial chambers when "Generate Structures" is turned on. The literal next version of the datapack seems to have addressed it (1.1.7), but for us since structures were off, we would have had to create the portal ourselves had we gotten to that point. It's also worth pointing out that this modpack does NOT create an island for each user, I had to do that manually as well using a structure block.*
